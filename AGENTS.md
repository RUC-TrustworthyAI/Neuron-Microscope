## Report and UI scope

- Follow the reference report structure and requested fields. Do not add unsolicited metadata tables, panels or warnings.
- Omit the entire Capture setting table.
- In activation-only reports, leave semantically selected example panels empty; do not substitute arbitrary extrema.
- Never feed official neuron descriptions or historical explanations into a fresh interpretation.
- Do not manually edit generated explanations, semantic labels, captions or HTML. Change the pipeline and regenerate.
- Keep full captured prefixes and explicit scoring positions. Scientific method changes must be documented separately from packaging changes.
- Keep credentials, API logs, model weights and activation archives out of Git.
- Do not add runtime acceptance gates, automatic retries or output truncation as part of repository cleanup.
